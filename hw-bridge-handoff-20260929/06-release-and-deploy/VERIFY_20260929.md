# Bridge 单实例发布与核验

本包以 `01-bridge/tencent-tangseng-bridge`、`03-php-deployment/backend` 为构建输入。叨叨业务服务端、悟空 IM、现有 MySQL/Redis/PHP 容器保持原部署。主备不在本次范围内。

## 本地构建

在交接包根目录执行，使用 Go 1.22：

```powershell
$go = 'C:\Users\Administrator\Desktop\tx2daodao\toolchain\go\bin\go.exe'
Push-Location '01-bridge/tencent-tangseng-bridge'
& $go test ./...
& $go vet ./...
Pop-Location
powershell -ExecutionPolicy Bypass -File '06-release-and-deploy/deploy-bridge-private-vpc.redacted.ps1' -PackageOnly -GoExecutable $go
powershell -ExecutionPolicy Bypass -File '06-release-and-deploy/deploy-php-bridge-provision.redacted.ps1' -PackageOnly
```

## 现网只读核验

SSH 公钥授权后，指定专用密钥。以下命令不读取或打印 `.env` 的内容：

```powershell
$key = "$HOME\.ssh\hw_bridge_20260929"
ssh -i $key -o IdentitiesOnly=yes ubuntu@101.32.11.27 'cd /opt/hw-bridge && docker compose --env-file .env ps && curl -fsS http://127.0.0.1:8090/healthz && curl -fsS http://127.0.0.1:8090/metrics | grep -E "bridge_(outbox_pending|outbox_dead|messages_done)" && sha256sum bridge'
ssh -i $key -o IdentitiesOnly=yes root@23.251.34.150 'cd /root/IM/YCH-IM-deploy && docker compose ps php worker && curl -ksS -o /dev/null -w "HTTP %{http_code}\n" -H "Host: admin.awhaha.com" http://127.0.0.1/ && sha256sum backend/application/api/model/User.php backend/application/imaccess/service/BridgeService.php backend/application/imaccess/controller/Bridge.php backend/config/im_bridge.php backend/route/route.php'
```

Bridge MySQL 的只读死信审计命令：

```bash
cd /opt/hw-bridge
docker compose --env-file .env exec -T mysql sh -c 'mysql -ubridge -p"$MYSQL_PASSWORD" bridge -e "SELECT status,COUNT(*) FROM bridge_outbox_job GROUP BY status; SELECT LEFT(last_error,120) AS error_prefix,COUNT(*) AS jobs FROM bridge_outbox_job WHERE status=\x27dead\x27 GROUP BY error_prefix ORDER BY jobs DESC LIMIT 30;"'
```

按 `bridge_message_mapping` 的 `done` 状态和目标侧消息记录逐条核对后才能重放。管理接口的 `GET /admin/dead-letter/` 返回不含消息正文的死信索引；`POST /admin/dead-letter/{job_id}` 会拒绝已完成映射及发送结果不明的任务，并在 `audit_log` 留下重放记录。不要对历史死信批量执行重放。

## 发布

脚本从服务器已有 `.env` 保留密钥；若有 `__SET_*__` 占位符会中止。先发布 Bridge，再发布 PHP 补丁：

```powershell
$key = "$HOME\.ssh\hw_bridge_20260929"
$go = 'C:\Users\Administrator\Desktop\tx2daodao\toolchain\go\bin\go.exe'
powershell -ExecutionPolicy Bypass -File '06-release-and-deploy/deploy-bridge-private-vpc.redacted.ps1' -ServerHost 101.32.11.27 -SshKeyPath $key -GoExecutable $go
powershell -ExecutionPolicy Bypass -File '06-release-and-deploy/deploy-php-bridge-provision.redacted.ps1' -ServerHost 23.251.34.150 -SshKeyPath $key
```

预期输出为 `HW_BRIDGE_DEPLOY_OK`、`PHP_BRIDGE_PROVISION_DEPLOY_OK`。Bridge 日志应出现 `account restore complete`、`tangseng proxy connecting`、`tangseng event accepted`；连续单聊后 `bridge_messages_done` 增加，`bridge_outbox_pending` 回落且 `bridge_outbox_dead` 不新增。重启 Bridge 后重复验证 PC(2) 自动恢复和双向单聊。
